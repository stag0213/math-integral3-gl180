# 円柱を平面で切った立体の体積 ― 可視化Webアプリ

円柱を斜めの平面で切った立体の体積を、3D表示・断面の観察・区分求積法・モンテカルロ法の4つの方法で調べる学習用Webアプリです。
HTMLファイル1つでできていて、ブラウザで開くだけで動きます。

## 問題

円柱

$$C : x^2 + y^2 \le 4,\quad 0 \le z \le 1$$

を考える。xy平面上の直線 $y = 1$ を含み、xy平面と $45^\circ$ の角をなす平面のうち、点 $(0, 2, 1)$ を通るものを $H$ とする。
円柱 $C$ を平面 $H$ で2つに分けたとき、点 $(0, 2, 0)$ を含む部分の体積 $V$ を求めよ。

## 答え

$$V = 3\sqrt{3} - \frac{4\pi}{3} \approx 1.007362$$

### 考え方

1. **平面 $H$ の式**
   $H$ は直線 $y = 1,\ z = 0$ を含み、傾きは $45^\circ$ で、点 $(0,2,1)$ を通ります。したがって
   $$H : z = y - 1$$

2. **求める部分**
   点 $(0,2,0)$ では $0 < 2 - 1$ なので、この点を含むのは $z \le y - 1$ の側です。
   $$x^2 + y^2 \le 4,\quad 0 \le z \le y - 1$$
   円柱の中では $y \le 2$ なので、$z \le 1$ は自動的に満たされます。

3. **体積（3通りの切り方）**

   | 切り方 | 断面の形 | 断面積 $S(t)$ | 積分区間 |
   |---|---|---|---|
   | $y = t$ | 長方形 | $2(t-1)\sqrt{4-t^2}$ | $1 \le t \le 2$ |
   | $z = t$ | 弓形 | $4\arccos\frac{1+t}{2} - (1+t)\sqrt{4-(1+t)^2}$ | $0 \le t \le 1$ |
   | $x = t$ | 直角二等辺三角形 | $\frac{1}{2}\left(\sqrt{4-t^2}-1\right)^2$ | $-\sqrt{3} \le t \le \sqrt{3}$ |

   いちばん計算しやすいのは $y = t$ で切る方法です。

   $$V = \int_1^2 2(y-1)\sqrt{4-y^2}\,dy = 2\sqrt{3} - \left(\frac{4\pi}{3} - \sqrt{3}\right) = 3\sqrt{3} - \frac{4\pi}{3}$$

## 機能

| 機能 | 内容 |
|---|---|
| 3D表示 | 円柱 $C$、平面 $H$、求める立体、点 $(0,2,1)$ と $(0,2,0)$ を表示します。マウスで回転・拡大・平行移動ができます。 |
| 表示の切り替え | 円柱・平面・立体・断面・乱数点を、チェックボックスで個別に表示／非表示にできます。 |
| 断面の観察 | 切る方向（$z=t$ / $y=t$ / $x=t$）を選び、スライダーで $t$ を動かすと、3D上の断面と2Dの投影図が連動して変わります。 |
| 区分求積法 | 断面積 $S(t)$ のグラフに中点和の長方形を重ねて描きます。分割数 $n$（1〜100）を変えると、近似値と厳密値の差がわかります。 |
| モンテカルロ法 | 箱 $[-2,2]\times[1,2]\times[0,1]$（体積4）に乱数の点を打ち、立体の中に入った点の割合から体積を推定します。点の数は1,000〜1,000,000から選べます。 |
| 厳密解 | 3通りの積分による導き方を、折りたたみ式で表示します。 |
| 数式表示 | KaTeX を使うので、根号・分数・積分記号がきちんと表示されます。 |

## 使い方

### 起動

`index.html` をブラウザで開いてください（ダブルクリックやドラッグ＆ドロップで開けます）。

ブラウザの設定によって、ローカルファイルのままでは外部モジュールを読み込めないことがあります。その場合は、簡単なローカルサーバーを立てて開いてください。

```bash
# Python 3 の場合
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### 操作

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 視点を回転 |
| ホイール | 拡大・縮小 |
| 右ドラッグ | 平行移動 |
| 「切る方向」ラジオボタン | 断面の向きを切り替え |
| $t$ スライダー | 断面の位置を移動 |
| $n$ スライダー | 区分求積の分割数を変更 |
| 「実行」ボタン | モンテカルロ法で推定 |

### 授業での使い方の例

1. 3D表示で平面 $H$ と、求める立体の形をつかむ。
2. 3通りの切り方で断面を観察し、どの断面がいちばん計算しやすいかを考える。
3. 区分求積法で $n$ を大きくし、どの切り方でも同じ値 $3\sqrt{3} - \frac{4\pi}{3}$ に近づくことを確かめる。
4. モンテカルロ法でも同じくらいの値になることを確かめる。

## 改造のヒント

- **平面の傾きや位置を変える**：断面積関数（`MODES`）、立体の生成部分、モンテカルロ法の判定式 `z <= y - 1` を合わせて書き換えます。
- **円柱の半径や高さを変える**：`CylinderGeometry` の引数、`circ()`、`segPts()` の半径 `2` を変更します。平面が上面と交わる場合は、立体の形が変わるので注意してください。
- **色の変更**：立体はオレンジ（`0xe67e22`）、平面は緑（`0x27ae60`）、断面は赤（`0xc0392b`）です。
